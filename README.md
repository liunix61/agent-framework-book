## ✨ 特性

- **完整覆盖**：从基础到进阶，从理论到实战
- **实战导向**：每个章节都包含完整的代码示例和实战项目

- **最佳实践**：包含安全、测试、性能优化、部署等最佳实践

## 🚀 快速开始

### 安装依赖

```bash
# Python 依赖
pip install -r requirements.txt

# C++ 依赖
# 见各章节的 C++ 代码示例
```

### 运行示例

```bash
# 运行 Python 示例
python examples/agent_example.py

# 运行 C++ 示例
g++ -o example examples/agent_example.cpp && ./example
```

1. 第1-3章：Agent 时代已经到来、Python/C++ Agent 开发基础、环境搭建与工具链
2. 第4-6章：Prompt Engineering 进阶、Context 管理、Harness 工具框架
3. 第7-9章：Loop 循环控制、Graph 图结构设计、Multi-Agent 协作
4. 第10-12章：记忆与知识管理、协议栈设计、Agent 系统部署
